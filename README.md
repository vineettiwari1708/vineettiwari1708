### About Me

I build complete, self-hosted software systems — from the database schema to the monitoring dashboard. I care about systems that actually run in production, not just on localhost.

- **Backend**: REST APIs, auth, multi-tenancy, background jobs
- **Frontend**: Dashboards, real-time charts, responsive UI
- **DevOps**: Docker, Nginx, auto-scaling, server monitoring
- **Focus**: Performance, observability, clean architecture

### Featured Projects

#### [ERP System](https://github.com/vineettiwari1708/erp-system)
Multi-tenant SaaS ERP built from scratch — invoicing, payments, ledger, role-based access, audit logs, and a full backup/restore system. Runs on Docker with PostgreSQL and Redis.

`Node.js` `React` `PostgreSQL` `Prisma` `Redis` `Docker` `TypeScript`

---

#### [ServerPilot](https://github.com/vineettiwari1708/serverpilot)
Self-hosted server monitoring dashboard. Lightweight agent reports CPU, RAM, disk, Docker containers, and live application metrics (req/s, error rate, latency) every 30 seconds. Real-time alerts, deployment tracking, and fault vs. load diagnosis.

`Node.js` `React` `TypeScript` `PostgreSQL` `Docker`

---

#### [Load Test](https://github.com/vineettiwari1708/load-test)
2-minute auto-scaling demo — injects CPU stress into a backend container, fires HTTP traffic through Nginx, and automatically scales replicas up/down based on CPU thresholds. Metrics visible live in ServerPilot.

`PowerShell` `Docker` `Nginx` `Node.js`
